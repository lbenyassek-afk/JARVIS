# JARVIS V8

JARVIS V8 is a native Python/PyQt6 Windows personal assistant created by
Reda Benyassek, built on the tested JARVIS V7 foundation.

- [Application guide](JARVIS-V8/README.md)
- [V8 plan and status](JARVIS-V8/V8_PLAN.md)
- [Architecture and release gates](JARVIS-V8/V6_ARCHITECTURE.md)

The workflow builds `JARVIS-V8-Setup.exe` as a prerelease. V8 installs beside
V6/V7 with its own profile, credentials and installer identity.
